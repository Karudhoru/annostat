# annostat

A Python tool for analyzing bacterial genome annotations from GFF3 and FASTA files.

## Features
- Sequence feature analysis (CDS, RNA counts, annotation checks)
- Tabular overview export (CSV/TSV)
- CDS sequence extraction (nucleotide + amino acid)
- Genome analysis (codon usage, COG categories)
- Visualizations of annotation data
